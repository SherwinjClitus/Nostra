# Nostra

A responsive ecommerce fashion website built as a frontend learning project. Nostra showcases modern web design principles with an intuitive interface for browsing fashion collections.

## Live Demo

[View Live Demo](https://sherwinjclitus.github.io/Nostra/)

## About the Project

Nostra is a fully responsive ecommerce website designed to demonstrate frontend development skills. The project features a clean, professional design with seamless navigation across desktop and mobile devices.

## Features

- **Responsive Navigation Bar** - Sticky navbar with smooth navigation links
- **Mobile Hamburger Menu** - Collapsible sidebar menu for mobile devices
- **Promotional Offer Banner** - Dismissable banner with special offer messaging
- **Image/Text Slider** - Multi-slide carousel with previous and next navigation controls
- **New Arrivals Section** - Display of newly added fashion items
- **Most Wanted Section** - Highlighted popular products with heart/wishlist icons
- **Product Collections** - Browse multiple fashion collections
- **Product Filtering** - Filter products by:
  - Occasion (Summer, Party, Beach)
  - Color (Red, Blue, White, Green)
  - Arrival Status (New, Old)
- **Contact Page** - Dedicated contact page for customer inquiries
- **Newsletter Subscription** - Email signup for exclusive updates and discounts
- **Responsive Design** - Optimized layouts for desktop, tablet, and mobile devices

## Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Responsive styling and layout
- **JavaScript (ES6)** - DOM manipulation and interactivity
- **Font Awesome** - Icon library for UI elements
- **Google Fonts (Poppins)** - Professional typography

## JavaScript Functionality

The project includes the following JavaScript features:

- **Mobile Menu Toggle** - Opens and closes the mobile sidebar navigation
- **Offer Banner Close** - Dismisses the promotional banner on click
- **Slider Navigation** - Previous/Next controls to cycle through multiple slides
- **Checkbox Filtering** - Real-time product filtering based on multiple criteria (occasion, color, arrival status)
- **DOM Event Listeners** - Interactive elements respond to user actions

## Responsive Design

The website is fully responsive with breakpoints optimized for:

- **Desktop** - Full navigation bar, multi-column product grids, and expanded layouts
- **Mobile** (max-width: 800px) - Hamburger menu replaces desktop navigation, offer banner is hidden
- **Mobile Collections** (max-width: 600px) - Adjusted filter panel, 2-column product grid, and smaller typography

Media queries ensure the design adapts gracefully to all screen sizes using relative units (viewport width percentages, vw).
